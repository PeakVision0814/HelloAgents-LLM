# Chapter 2: History of Agents

从 ELIZA 开始，理解 AI Agent 的起源——最简单的规则式对话系统。

## Files

| File | Description |
|------|-------------|
| `ELIZA.py` | 简化版 ELIZA，用正则匹配 + 模板回复模拟心理治疗师对话 |

## Quick Start

```bash
# 零依赖，直接运行
python ELIZA.py
```

输入 `quit`、`exit` 或 `bye` 结束对话。

## Key Concepts

- **Pattern Matching**: 正则规则驱动回复选择
- **Pronoun Reversal**: 第一/第二人称转换（I → you, you → I）
- **Template Response**: 预设回复模板 + 随机采样
- 这是 AI Agent 的起点：没有真正的"智能"，但展现了对话式交互的基本范式
